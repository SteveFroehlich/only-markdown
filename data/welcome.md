# Welcome

This is the **Only Markdown** sample file. Edit it in any editor, then press `⌘⇧8` (or `Ctrl+Shift+8`) in the browser to refresh the preview.

## Features in v0

- GFM-style markdown (tables, strikethrough, fenced code)
- Local preview only — no in-app editing
- On-demand refresh (not auto on save)

| Layer | Role |
| --- | --- |
| Processing | `.md` → HTML on the server |
| Display | Theme + chrome around that HTML |
